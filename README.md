# GAMESWARD

> **GAMESWARD** — *от games (игры) и -ward (направление, сторона)*.  
> **Ваш проводник в мир настольных игр**.

**GAMESWARD** — это открытая платформа для игры «один на один» в настольные игры (шахматы, шашки, крестики-нолики и другие). Проект создан как **шаблон для студентов** и как **основа для коммерческих игровых сервисов** (например, CHESSWARD).

---

## 🎯 Цели проекта

1. **Создать образовательный стенд** для студентов, изучающих Django + React.
2. **Показать модульную архитектуру**: ядро + игровые движки + фабрика.
3. **Дать основу для дипломных проектов**: каждая игра — отдельный модуль.
4. **Построить расширяемую платформу**, готовую к добавлению новых игр.

---

### Ключевые архитектурные решения

| Слой                    | Назначение                  | Расширяемость                   |
| :---------------------- | :-------------------------- | :------------------------------ |
| **Ядро (core/)**        | Настройки, маршруты         | Не изменяется                   |
| **Приложения (apps/)**  | Пользователи, комнаты, игры | Новое приложение не ломает ядро |
| **Сервисы (services/)** | Игровые движки              | Новый движок — новый файл       |
| **API (api/)**          | Версионированные эндпоинты  | v2 без изменения v1             |

### Поддерживаемые игры

| Игра                | Тип                | Статус                               |
| :------------------ | :----------------- | :----------------------------------- |
| **Крестики-нолики** | `tictactoe`        | ✅ Работает                           |
| **Русские шашки**   | `russian_checkers` | ✅ Работает (включая серийное взятие) |

## 🚀 Быстрый старт

### 1. Клонировать репозиторий
```bash
git clone https://github.com/kvm64/gamesward.git
cd gamesward
```

### 2. Бэкенд (Django)

bash

```
python -m venv .venv
.venv\Scripts\activate     # Windows
source .venv/bin/activate  # Linux/Mac
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python scripts/create_roles.py
python manage.py runserver
```



### 3. Фронтенд (React)

bash

```
cd frontend
npm install
npm start
```
