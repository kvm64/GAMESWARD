# GAMESWARD — ROADMAP

План развития платформы: архитектура страниц, этапы, приоритеты.

---

## 🗺 Карта страниц

### Публичная часть (неавторизованные)

| Путь        | Назначение                                                   |
| ----------- | ------------------------------------------------------------ |
| `/`         | Лендинг: что такое GAMESWARD, возможности, скриншоты, кнопки «Войти» / «Регистрация» |
| `/login`    | Вход                                                         |
| `/register` | Регистрация                                                  |

### Авторизованная часть

| Путь                      | Назначение                                                   |
| ------------------------- | ------------------------------------------------------------ |
| `/play`                   | **Лобби.** Мои активные игры, входящие/исходящие приглашения, кнопка «Начать новую игру» |
| `/profile`                | **Личный кабинет.** Профиль, статистика, настройки. Открывается в новой вкладке по кнопке «ЛК» |
| `/game/:gameType/:gameId` | **Игровая комната.** Доска, статус. Открывается в новой вкладке |
| `/admin/`                 | Django-админка (для админов)                                 |

### Редиректы

- Авторизованный + `/` → редирект на `/play`
- Неавторизованный + `/play` → редирект на `/` (лендинг)

### Шапка (navbar)

```
┌──────────────────────────────────────────────────────────────┐
│ 🎮 GAMESWARD   │ Играть │ ЛК │ 🔔📨(2) │  👤 admin ▾         │
└──────────────────────────────────────────────────────────────┘
```

- **🎮 GAMESWARD** — логотип, клик → `/play` (или `/` для гостя)
- **Играть** — `/play` (лобби)
- **ЛК** — `/profile` в новой вкладке (`target="_blank"`)
- **🔔📨 (N)** — счётчик новых приглашений, клик → `/play` (секция «Входящие»)
- **👤 admin ▾** — выпадающее меню: Профиль, Настройки, Выйти

## 🎯 Принципы

1. **MVP сначала, оптимизация потом.** Polling работает → WebSocket позже.
2. **Каждая фаза — отдельная ветка + PR** (или коммит в `main`, если соло).
3. **Каждая правка — закоммичена.** Не оставлять «грязное» дерево.
4. **Документация — рядом с кодом.** `docs/TECH_DECISIONS.md`, `docs/ROADMAP.md`.
5. **`.env` — только в `.gitignore`.** Секреты не коммитим никогда.

## 📌 Известные проблемы (техдолг)

| Проблема                                             | Решение                           | Приоритет   |
| ---------------------------------------------------- | --------------------------------- | ----------- |
| Протухание access-токена (12 ч)                      | Авто-refresh в `client.js`        | Средний     |
| Поллинг каждые 2 сек                                 | WebSocket (Фаза 4)                | Низкий      |
| У отправителя (A) игра не открывается после принятия | Polling приглашений или WebSocket | Средний     |
| Нет экрана «Мои активные игры»                       | Фаза 2                            | Высокий     |
| F5 ломает сессию (теряется `gameId`)                 | localStorage (Фаза 2)             | **Высокий** |
| Нет лендинга для гостей                              | Фаза 2                            | Средний     |
